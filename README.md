# Task Manager (Rabby)

Task manager with stable block-ID identity, atomic writes, quick-add parsing and undo.

Works on desktop and mobile.

## Install with BRAT

1. Install **BRAT** from Obsidian's Community plugins and enable it.
2. Open the command palette → **BRAT: Add a beta plugin for testing**.
3. Paste `rabby0101/obsidian-task-manager` and click **Add Plugin**.
4. Enable **Task Manager (Rabby)** in Settings → Community plugins.

BRAT keeps the plugin updated from this repo's releases.

## Manual install

Download `main.js`, `manifest.json` and `styles.css` from the latest release into
`<your vault>/.obsidian/plugins/rabby-task-manager/`, then enable the plugin.
